เปิดไฟล์เพื่อเริ่มอ่าน

รองรับ iPad / Apple Pencil / Safari เปิด PDF ข้อความ, PDF สแกน/รูปภาพ (OCR อัตโนมัติ), ซูม/ข้ามหน้า/จำหน้าล่าสุด และคลังศัพท์ส่งออก CSV

แตะลากคลุมคำหรือประโยคในเอกสาร (หรือใช้ Apple Pencil ลากในโหมดครอป) ผลแปลจะแสดงทันทีที่นี่

หากลากคลุมคำใน iPadOS ไม่ติด ให้กดปุ่ม ครอปแปลไว (OCR) แล้วลากกรอบคลุมคำที่ต้องการได้เลยครับ

วางข้อความหรือเนื้อหาจากเว็บ

ตั้งค่า Gemini, ระบบ OCR และพฤติกรรมการใช้งาน

การแปลคำและระบบ OCR ทำงานฟรีทันทีโดยไม่ต้องใช้ API Key ส่วน API Key ด้านล่างใช้สำหรับปุ่มครอปโจทย์ให้ AI วิเคราะห์
